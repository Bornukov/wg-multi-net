# wg-multi-net

Развёртывание WireGuard-сервера с несколькими изолированными сетями, единым веб-порталом и мониторингом подключений.

## Возможности

- Несколько изолированных VPN-сетей (например, `10.197.1.0/24` … `10.197.4.0/24`)
- Управление устройствами через `wg-access-server` (веб-интерфейс для каждой сети)
- Единый портал с кнопками сетей и таблицей активных подключений
- Централизованное хранение имён сетей (REST API на Flask)
- Клиенты не выходят в интернет через VPN (NAT отключён)
- Автоматическое обновление SSL-сертификата (NetAngels)
- Клиенты: Linux, Windows, macOS, Android, iOS
- Каждая сеть — отдельный Docker-контейнер, полная изоляция

## Требования

- VPS с Debian 12/13
- Статический IP-адрес
- Домен (для SSL и поддоменов сетей)
- SSL-сертификат (например, от NetAngels) — если планируете использовать HTTPS
- API-ключ NetAngels — если хотите автоматическое обновление сертификата
